## About This Repository

**PHP Academic Skills** is a learning repository dedicated to PHP programming exercises and academic practical work.

It serves as a space to organize PHP learning activities, practice programming concepts, and keep track of practical exercises completed during academic training.

The repository is structured into different directories to organize the available activities.

## Repository Structure

```text
PHP_academic_skills/
│
├── activite1-fonctions/
│   └── PHP exercises related to functions
│
├── tp1/
│   └── First practical work
│
└── README.md
```

## Contents

| Directory | Description |
|---|---|
| `activite1-fonctions/` | Academic activity related to PHP functions |
| `tp1/` | First practical work (TP1) |

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/saadayoujil-dev/PHP_academic_skills.git
```

### 2. Navigate to the project directory

```bash
cd PHP_academic_skills
```

### 3. Explore the exercises

Open the repository directories and explore the available PHP files.

## Running PHP Exercises

PHP files can be executed using a PHP environment.

For a PHP file, the general command-line format is:

```bash
php filename.php
```

Replace `filename.php` with the actual PHP file you want to execute.
